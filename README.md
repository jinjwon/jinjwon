### 김진원 · `jinjwon`

바이브 코딩으로 직접 만드는 프로덕트 디자이너.<br>
리서치로 문제를 정의하고, 화면을 설계하고, 돌아가는 것까지 만듭니다.

```yaml
# persona.yml
name: 김진원
role: Product Designer
mode: design → prototype → ship

goals:
  - 시안에서 끝나지 않고 실제로 동작하는 결과물 만들기
  - 사용자 리서치를 근거로 문제부터 정의하기
  - 디자인과 개발 사이의 간격 줄이기

behaviors:
  - 화면을 그리기 전에 플로우와 상태(empty · loading · error)부터 정리
  - 설명보다 프로토타입으로 먼저 보여주기
  - AI 코딩 도구로 아이디어를 바로 빌드해서 검증

stack:
  design: [Figma, Framer, Illustrator, Photoshop, Blender]
  build:  [TypeScript, JavaScript, HTML/CSS, Godot, Unity]
  with:   [Claude Code, Codex]
```
