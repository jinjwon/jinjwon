# 페르소나 UI 스타일 방향 (프로필 화면 기준)

프로필 화면(`assets/screen.gen.py`)을 고칠 때의 기준입니다. "개발사 설명"은 인터뷰에서 확인한 내용이고,
"화면 관찰"은 영상·스크린샷을 보고 정리한 것입니다. 원작의 캐릭터 그림·로고·전용 서체는 쓰지 않습니다.

## 한눈에 비교

| | P3 리로드 | P4 리바이벌 | P5 |
|---|---|---|---|
| 한 줄 방향 | 물속으로 가라앉는 고요함 | 화창한 낮 + TV 너머의 이상함 | 반항적인 팝 펑크 |
| 주색 | 바다색 파랑 | 선명한 노랑 | 강렬한 빨강 |
| 보조색 | 하늘색, 흰색 (선택: 빨강·분홍) | 검정·짙은 보라, 하늘색, TV 다색 | 검정·흰색만 |
| 글자 | 굵은 이탤릭 고딕 | 굵은 세리프 | 글자마다 다른 오려 붙이기 |
| 구도 | 왼쪽 캐릭터, 가운데 기운 메뉴 | 대각선 면 분할, 대각선 계단 메뉴 | 강한 사선, 비대칭 |
| 움직임 | 느리고 우아함 | 경쾌함, 색 번짐 | 빠르고 공격적 |

## P3 리로드 (06~12시)

**개발사 설명** ([Famitsu 인터뷰 정리](https://personacentral.com/p3r-interview-menu-ui/))
- UI는 주인공의 내면을 비춥니다. 메뉴를 여는 것은 마음속으로 가라앉는 일입니다.
- 색은 바다 같은 파랑입니다. 물속 일렁임, 그러데이션, 거품, 유리 같은 반짝임으로 물을 표현합니다.
- 움직임은 P5의 빠른 팝 펑크를 피하고, 우아하고 덧없게 만듭니다.

**화면 관찰**
- 메뉴 단어는 넓고 무거운 이탤릭이며, 단어마다 크기가 다르고 줄이 서로 물립니다.
- 선택 단어는 빨강이고 일부가 검정으로 갈립니다. 뒤에 흰 칼날과 분홍 칼날이 뻗습니다.
- 왼쪽에는 화면 밖으로 잘리는 큰 세로 글자(검정)와 큰 회색 숫자, 작은 흰 정보 상자가 있습니다.
- 오른쪽 아래는 설명 한 줄 + 밑줄 + 작은 라벨, 그 아래 원형 버튼 안내입니다.

**하지 않는 것**: 번쩍이는 전환, 화면을 가로지르는 띠, 딱딱한 사각 패널.

## P4 리바이벌 (12~18시)

**개발사 설명** (P4 원작 기준, [Atlus UI 강연 정리](https://personacentral.com/persona-5-panel-concept-development-ui/), [Siliconera](https://www.siliconera.com/atlus-reveals-design-secrets-behind-persona-5s-distinctive-ui/))
- 밝은 노랑은 "레트로 + 팝"입니다.
- 이야기의 열쇠인 TV를 다색 줄무늬로 나타내고, 화려한 색에 묻히지 않게 검정을 씁니다.

**화면 관찰** (리바이벌 데모 일시정지·스킬·장비 화면)
- 노란 면을 큰 대각선이 가르고, 그 틈으로 파란 하늘과 흰 구름이 보입니다.
- 메뉴 단어는 **굵은 세리프**(대소문자 혼용)이며, 오른쪽 아래로 계단처럼 내려가고 전체가 기울어 있습니다.
- 위쪽 항목은 어두운 글자, 아래쪽 어두운 면 위의 항목은 노란 글자입니다. 모두 짙은 그림자가 있습니다.
- 선택 항목은 크게 커지고 흰색이 되며, 빨강·초록·파랑이 어긋난 TV 색 번짐이 생기고 뒤에 흰·파랑 조각이 붙습니다.
- 오른쪽 아래의 짙은 보라 덩어리, 크고 둥근 꽃, 흩날리는 노란 잎.
- 왼쪽 캐릭터는 크게 잘려 들어옵니다. 오른쪽 아래에 어두운 알약 모양 도움말, 아래 가운데에 소지금.

**하지 않는 것**: 네모난 목록 바, 좁은 고딕, 주사선만으로 TV 표현하기, 차가운 단색 배경.

## P5 (18~06시)

**개발사 설명** (아트 디렉터 스도 마사요시, [강연 정리](https://personacentral.com/persona-5-panel-concept-development-ui/), [Famitsu 인터뷰](https://segabits.com/blog/2016/09/12/extensive-famitsu-interview-persona-5-art-audio-leads/))
- 콘셉트는 "팝 펑크"입니다.
- 빨강이 돋보이도록 보조색을 최대한 넣지 않습니다. 글자는 검정과 흰색입니다.

**화면 관찰**
- 글자마다 서체·크기·각도가 다른 오려 붙이기 글자, 별과 날카로운 사선, 망점.
- 선택 항목은 색이 뒤집히고 튀어나옵니다.

**프로필 화면의 선택**: 메뉴 화면의 손 그림은 직접 그리면 어색해서 빼고, 타이틀 화면 구성(큰 몽타주 로고 + 타이틀 메뉴)을 씁니다.
**하지 않는 것**: 파랑·노랑 같은 보조색, 부드러운 곡선 위주의 움직임.

## 공통 규칙

- 내용(프로젝트, 최근 저장소, 링크)은 같고, 구도·글자·선택 표시·움직임은 테마마다 따로 만듭니다.
- 선택 항목은 어느 테마든 1초 안에 눈에 띄어야 합니다.
- GitHub README 제약: 스크립트 없음(SVG 애니메이션만), 이미지 안 클릭 불가, 글꼴은 SVG에 내장.
- 캐릭터 자리는 프로필 사진을 테마 색으로 단색화해서 씁니다.
